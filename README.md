## A — Project

- **A1** — The project root contains an `images/` folder with images.
- **A2** — The project root contains a `css/` folder with a stylesheet file.
- **A3** — All styles are written in one file `styles.css`, located in the `css/` folder.
- **A4** — File names do not contain **uppercase letters, spaces, transliteration** — only lowercase English letters and words.
- **A5** — The source code is formatted using **Prettier**.
- **A6** — All images and text content are taken from the layout.
- **A7** — The style normalizer **[modern-normalize](https://github.com/sindresorhus/modern-normalize)** is connected.
- **A8** — All raster images are optimized using **[Squoosh](https://squoosh.app/)**.
- **A9** — The code is written according to the recommendations of **[Code Guide](https://codeguide.co/)**.

---

## B — Markup

- **B1** — The markup for the **Our Portfolio** section is implemented in the `index.html` file. The HTML markup of **all layout elements** is completed.
- **B2** — Tags are used according to their **semantic meaning**.
- **B3** — HTML passes validation in **[W3C Validator](https://validator.w3.org/nu/#textarea)** **with no errors**.
- **B4** — Class names are **descriptive and clear** to another developer.
- **B5** — Class names do not contain **uppercase letters, spaces, transliteration, or tag names**. Only English words. If multiple words — separated with a hyphen.
- **B6** — `<img>` tags specify size attributes, at least `width`.
- **B7** — Images are exported in **.jpg** format.
- **B8** — Groups of similar elements are arranged in `<ul>` lists.
- **B9** — All required fonts and their variations (weight and style) are connected from **Google Fonts** using one link.  
  Required weights:
  - **Raleway — 700**
  - **Roboto — 400, 500, 700**

---

## C — Styling

- **C1** — **Class selectors** are used for styling.
- **C2** — There is **no `!important`** in the styles.
- **C3** — Interactive elements (buttons, links) have active hover/focus states according to the **[Style Guide](<https://www.figma.com/file/wuEpGhwCepGCOUw7mZFRac/Web-Studio-(Version-5.0)?type=design&node-id=296641-536&mode=design&t=HqslgV0OjDOknzIj-0>)**.
- **C4** — Contact text in the header changes color on **hover and focus**.
- **C5** — `body` is assigned a `font-family` with the dominant **Roboto** font.
- **C6** — Alternative font options and the font family type (sans-serif) are listed at the end of `font-family`.
- **C7** — The **Roboto** font is set explicitly only for `body`, all other elements **inherit** it.
- **C8** — `body` has the `color` property assigned with the dominant text color.
- **C9** — `font-size` of all text elements **matches the layout exactly**.
- **C10** — `line-height` is set as a **multiplier**, not in `px`.
- **C11** — `color` and `background-color` values of all elements match the layout precisely.
- **C12** — `font-weight` of all elements matches the layout; it is explicitly defined only when it differs from the default.
- **C13** — Buttons are assigned `cursor: pointer`.
- **C14** — Default browser values are **not duplicated** in the styles.
