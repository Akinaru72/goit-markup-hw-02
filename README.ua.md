# goit-markup-hw-02

- Склонуй створений репозиторій і скопіюй у нього файли попередньої роботи.

- Виконай розмітку і оформлення макета сторінки для **[домашнього завдання №2](<https://www.figma.com/file/wuEpGhwCepGCOUw7mЗFRac/Web-Studio-(Version-5.0)?type=design&node-id=302815-2553&mode=design&t=HqslgV0OjDOknzIj-0>)**.

- Для оптимізації зображень використовуй сервіс **[Squoosh](https://squoosh.app/)**.

- Налаштуй **GitHub Pages** і додай посилання на живу сторінку в секцію **About** GitHub-репозиторія.

---

## A — Проєкт

- **A1** — У корені проєкту є папка `images/` із зображеннями.
- **A2** — У корені проєкту є папка `css/` із файлом стилів.
- **A3** — Всі стилі написані в одному файлі `styles.css`, який знаходиться в папці `css/`.
- **A4** — У назвах файлів немає **великих літер, пробілів, трансліту** — тільки малі англійські літери та слова.
- **A5** — Вихідний код відформатований за допомогою **Prettier**.
- **A6** — Всі зображення та текстовий контент взяті з макета.
- **A7** — Підключений нормалізатор стилів **[modern-normalize](https://github.com/sindresorhus/modern-normalize)**.
- **A8** — Всі растрові зображення оптимізовані через **[Squoosh](https://squoosh.app/)**.
- **A9** — Код написаний із дотриманням рекомендацій **[Code Guide](https://codeguide.co/)**.

---

## B — Розмітка

- **B1** — Розмітка секції **Our Portfolio** виконана у файлі `index.html`. Зроблена HTML-розмітка **всіх елементів макета**.
- **B2** — Теги використані відповідно до їх **семантичного змісту**.
- **B3** — HTML проходить перевірку валідатором **[W3C Validator](https://validator.w3.org/nu/#textarea)** **без помилок**.
- **B4** — Імена класів **описові та зрозумілі** іншому розробнику.
- **B5** — Імена класів не містять **великих літер, пробілів, трансліту чи назв тегів**. Тільки слова англійською. Якщо декілька слів — розділені дефісом.
- **B6** — У тегів `<img>` вказані атрибути розмірів, як мінімум `width`.
- **B7** — Зображення експортовані у форматі **.jpg**.
- **B8** — Групи однотипних елементів оформлені у списки `<ul>`.
- **B9** — Всі необхідні шрифти та їх варіації (вага і накреслення) підключені через **Google Fonts** одним посиланням.  
  Необхідні ваги:
  - **Raleway — 700**
  - **Roboto — 400, 500, 700**

## C — Оформлення

- **C1** — Для оформлення використовуються **селектори класу**.
- **C2** — У стилях **немає `!important`**.
- **C3** — Інтерактивні елементи (кнопки, посилання) на **hover/focus** мають активний стан, згідно **[Style Guide](<https://www.figma.com/file/wuEpGhwCepGCOUw7mZFRac/Web-Studio-(Version-5.0)?type=design&node-id=296641-536&mode=design&t=HqslgV0OjDOknzIj-0>)**.
- **C4** — Текст контактів у хедері змінює колір при **hover і focus**.
- **C5** — Для `body` задано `font-family` з домінантним шрифтом **Roboto**.
- **C6** — Вказані альтернативні варіанти шрифту й тип сімейства (без зарубок) наприкінці `font-family`.
- **C7** — Шрифт **Roboto** явно задано тільки для `body`, інші елементи **наслідують** його.
- **C8** — Для `body` задано властивість `color` з домінантним кольором тексту.
- **C9** — `font-size` всіх текстових елементів **точно відповідає макету**.
- **C10** — `line-height` у вигляді **множника**, а не `px`.
- **C11** — `color` та `background-color` всіх елементів точно відповідають макету.
- **C12** — `font-weight` усіх елементів відповідає макету; явно вказується лише якщо відрізняється від дефолтного.
- **C13** — Кнопкам задано `cursor: pointer`.
- **C14** — У стилях **не дублюються дефолтні значення** браузера.
